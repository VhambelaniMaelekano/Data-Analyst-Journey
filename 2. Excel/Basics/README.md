# Excel Basics Project – Sales Data

## 📊 Project Overview
This project demonstrates foundational Excel skills:
- Using formulas (`SUM`, `AVERAGE`, `COUNT`)
- Applying conditional formatting
- Sorting and filtering data
- Creating summary statistics
- Building pivot tables and charts


## 🗂 Dataset
- **Name:** Sample Sales Data.csv
- **Columns:** OrderID, Region, Product, Sales, Quantity, Revenue per Unit
- **Rows:** 10 transactions

## 🔧 Steps Taken
1. **Data Cleaning**
   - Checked for missing values
   - Removed duplicates
   - Ensured consistent formatting

2. **Analysis**
   - Calculated total sales using `SUM`
   - Found average sales using `AVERAGE`
   - Counted transactions using `COUNT`

3. **Conditional Formatting**
   - Highlighted sales above 12,000 in green
   - Highlighted sales below 6,000 in red

4. **Sorting & Filtering**
   - Sorted by Region and Product
   - Filtered to show only Laptop sales

## 📈 Insights
- Highest sales transaction: R15,000 (Laptop, West region)
- Lowest sales transaction: R4,200 (Tablet, East region)
- Average sales across all transactions: R9,690
- Laptops dominate both total sales and per-unit revenue
- South region leads efficiency (highest revenue per unit)
- East region recorded the highest overall sales (R27,200)
