# Git Basics Notes

## What is Git?

Git is a version control system that helps track changes in files and projects over time.
It allows you to save different versions of your work and go back to earlier versions if needed.

Git is especially useful when working on projects, collaborating with others, or managing updates.

---

## Key Concepts

### Repository (Repo)
A repository is a project folder that Git tracks. 
It stores your files and the history of changes made to them.

### Commit
A commit is like taking a snapshot of your project at a specific point in time.

### Branch
A branch allows you to work on new features or changes without affecting the main version of your project.

### Remote Repository
A remote repository (such as GitHub) stores your project online so it can be backed up or shared.

---

## Common Git Commands

git init  
Creates a new Git repository.

git status  
Shows the current state of your files.

git add .  
Stages all changes for the next commit.

git commit -m "message"  
Saves changes with a descriptive message.

git push origin main  
Uploads your changes to GitHub.

git pull  
Downloads updates from the remote repository.

git clone  
Copies a repository from GitHub to your local machine.

git log  
Shows the history of commits.

Git helps track project versions, organize workflows, and manage updates when working on data analysis projects.
